# Legacy static starter

`haaglanden-tournamentos-prototype/` is the extracted earlier working HTML/CSS/JS prototype.

It includes public hub, dashboard, tournaments, matches, Match Centre, clubs, players, team manager, referees, discipline, messages, media, PWA manifest and service worker.

Use it to:

- inventory earlier routes and UI copy;
- preserve useful working interactions;
- compare role and Match Centre flows;
- reuse local logo/reference assets where appropriate.

Do **not** treat its visual system or static architecture as the final target. The premium specification, five concept boards and current feature register supersede it. If a newer application already exists on the VPS, do not copy this starter over it.
