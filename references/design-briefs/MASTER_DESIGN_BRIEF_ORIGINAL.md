# MASTERPROMPT — Haaglanden Voetbal TournamentOS

## 5× Ultra-Detailed 8K Enterprise Dashboard Mock-up Showcases

Create **five completely different, ultra-detailed, photorealistic 8K UI/UX product showcase images** for the new **Haaglanden Voetbal TournamentOS**.

The five images must show the same software platform from the perspective of five different user roles:

1. Tournament Management / Toernooileiding
2. Match Operations / Wedstrijdleiding
3. Club Administrator
4. Team Manager
5. Referee / Scheidsrechter

These are NOT five unrelated dashboard concepts.

They must clearly belong to **one coherent enterprise sports software ecosystem**, using the same design system, navigation principles, typography, components, iconography, branding and interaction language.

However, every role must have its own dashboard hierarchy, information density, shortcuts, alerts, KPIs and workflows.

The result should feel like a premium combination of:

- ESPN digital sports products
- UEFA tournament interfaces
- modern enterprise SaaS
- Stripe Dashboard
- Linear
- premium sports broadcast graphics
- professional tournament operations software

Do NOT make it look like a generic admin template.

Do NOT make it look like an amateur football website.

Do NOT create a dark cyberpunk dashboard.

The primary visual direction is:

**LIGHT • PREMIUM • ENTERPRISE • SPORTS • DATA-RICH • EDITORIAL • MODERN**
